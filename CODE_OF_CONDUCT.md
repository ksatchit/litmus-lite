# Code of Conduct

litmus-lite follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). It applies in the repository, its issues and pull requests, and any space where you speak for the project.

In short: be respectful, be welcoming, assume good faith, and keep the discussion about the work. Harassment, discrimination and personal attacks are not accepted.

To report a violation, write to karthik.s@harness.io. Reports are handled in confidence. If the report is about the maintainer, write to the CNCF Code of Conduct Committee at conduct@cncf.io.
